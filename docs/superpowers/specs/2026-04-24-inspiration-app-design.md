# 灵感记录App · MVP设计规格

> 创建日期：2026-04-24  
> 平台：移动端（iOS + Android）  
> 风格：治愈系

---

## 🎯 产品定位

帮助用户随时记录日常小灵感与感触，通过极简交互和治愈视觉，让记录本身成为一种放松体验。

---

## 📱 技术选型

| 模块 | 技术方案 | 说明 |
|------|----------|------|
| 框架 | Flutter 3.x | 跨平台，一套代码生成iOS+Android |
| 状态管理 | provider | 轻量响应式，学习成本低 |
| 本地存储 | Hive 2.x | 轻量NoDB，支持对象序列化 |
| 图片处理 | image_picker + image_cropper | 系统相册选择 + 基础裁剪压缩 |

---

## 🗂️ 数据模型

### Inspiration (Hive Object)
```dart
@HiveType(typeId: 0)
class Inspiration {
  @HiveField(0) final String id;          // UUID v4
  @HiveField(1) final String content;     // 灵感内容（必填，上限2000字）
  @HiveField(2) final DateTime createdAt; // 创建时间（精确到秒）
  @HiveField(3) final List<String> tags;  // 标签列表，如 ['工作', '创意']
  @HiveField(4) final String? imagePath;  // 可选：本地图片相对路径
  @HiveField(5) final bool isArchived;    // 是否归档（默认false）
}
```

### 存储策略
- Hive Box名称：`inspirations`
- 图片存储：`app_documents/inspiration_images/{uuid}.jpg`
- 自动备份：每日首次启动时导出JSON到`app_documents/backups/`（可选）

## 🎨 视觉规范

### 色彩体系（治愈莫兰迪）
```
主背景：#F8F5F2（暖米白） / #F0F4F8（淡雾蓝，可切换）
卡片背景：#FFFFFF + boxShadow(elevation: 2, blur: 8)
正文文字：#333333（主） / #666666（次要） / #999999（禁用）
强调色：#A8D5BA（薄荷绿，用于按钮/高亮）
成功色：#B8D8BE / 警告色：#E8C5A8 / 错误色：#E8B4B8

深色模式
背景：#1A1F26 / 卡片：#242B33 / 文字：#E6E6E6 / 强调：#7FB89A
```

### 组件规范
```
圆角：卡片16px / 按钮24px(全圆) / 输入框12px / 标签8px
阴影：卡片 (0,2,8,0.1) / 悬浮按钮 (0,4,16,0.15)
字体：系统默认无衬线 / 正文14sp / 标题18sp / 小字12sp
间距：基础单位8px，行距1.6倍，段落24px
```

### 动效原则
- 按钮按压：scale 0.95 + 100ms缓动
- 列表滑动：Curves.easeOut滑动曲线
- 保存成功：轻微粒子扩散 + 0.3s淡出
- 页面切换：SlideTransition + FadeTransition组合

## ⚡ 核心功能流程

### 1. 极速输入（首页）
```
触发：点击首页右下角悬浮「+」按钮
交互：
  1. 底部面板滑出（高度60%屏幕）
  2. 键盘自动聚焦，光标定位输入框
  3. 输入区域上方显示工具栏：[🏷️标签] [📷图片] [🎤语音]
  4. 输入内容实时显示字数（上限2000）
  5. 点击「保存」→ 校验非空 → Hive写入 → 轻微成功动效 → 面板收起
  6. 空内容时「保存」按钮置灰，提示「写点什么吧～」

异常处理：
  - 图片选择取消：静默关闭，不影响输入
  - 图片加载失败：提示「图片加载失败，已跳过」+ 继续文字记录
  - 存储失败：内容暂存剪贴板 + 友好提示 + 重试按钮
```

### 2. 标签分类
```
入口：底部导航「标签」页
展示：
  - 标签云布局：按使用频率降序，字体大小12-20sp渐变
  - 每个标签显示：名称 + 使用次数 + 颜色徽章（随机莫兰迪色）
交互：
  - 点击标签：过滤首页时间线，仅显示含该标签的灵感
  - 长按标签：弹出菜单 [编辑名称] [删除] [查看统计]
  - 删除标签：仅移除标签关联，不删除灵感内容（二次确认）
```

### 3. 时间线回顾
```
默认视图：首页主区域，按createdAt倒序排列
卡片设计：
  ┌─────────────────┐
  │ 2026.04.24 14:30 │ ← 右上角日期角标
  │                 │
  │ 今天想到...     │ ← 内容预览（最多3行，省略号截断）
  │                 │
  │ [工作][创意]    │ ← 标签徽章（最多3个，超出显示+2）
  └─────────────────┘
交互：
  - 下拉刷新：本地数据无需网络，展示轻微刷新动效
  - 点击卡片：进入详情页（支持编辑/分享/归档）
  - 长按卡片：快速操作菜单 [编辑] [删除] [复制]
  - 空状态：手绘插画 + 「记录第一缕灵感吧」+ 引导按钮

那年今日（预留）：
  - 每日首次打开时，随机展示一条去年今日的灵感
  - 卡片顶部显示「🌸 去年今天的你」+ 内容 + 「再写一条」按钮
```

## ✨ 治愈感细节

### 微文案设计
```
首次启动：「欢迎来到心流屋，记录每一刻闪光✨」
输入框提示：「今天有什么小灵感？」
保存成功：「已收藏这份灵感🌿」
空标签页：「还没有标签，先记录再分类吧～」
删除确认：「确定要放下这份灵感吗？（3秒后可撤销）」
```

### 感官体验
- 🌤️ 每日一句：本地文案库随机展示治愈短句（可关闭）
- 🎵 轻反馈：保存/删除等操作可选开启柔和提示音
- 🎨 主题切换：设置页提供3套治愈配色方案
- 📝 输入陪伴：键盘上方显示实时字数 + 鼓励小动画（每100字触发）

## ⚠️ 错误处理

| 场景 | 用户提示 | 系统行为 |
|------|----------|----------|
| 图片加载失败 | 「图片加载失败，已跳过」 | 继续保存文字内容 |
| 存储空间不足 | 「保存失败，请清理空间」 | 内容暂存剪贴板 + 提供复制按钮 |
| 应用意外退出 | 「发现未保存内容，是否恢复？」 | 读取30秒自动草稿缓存 |
| 删除操作 | 「确定删除？3秒内可撤销」 | 延迟执行 + 显示撤销Snackbar |

原则：所有提示用温和文案，避免技术术语；关键操作支持撤销。
